# Movie App (Flutter)

A feature-rich Movie & TV Show application built with Flutter using the TMDB API.

Features

1.  Browse Trending, Popular, and Top-Rated Movies & TV Shows
2.  Detailed movie/TV information (overview, rating, posters, etc.)
3.  Authentication & Account-based Watchlist
4.  Add/Remove from Watchlist
5.  Pagination with smooth scrolling
6.  Clean and responsive UI

Tech Stack

1.  Flutter & Dart
2.  Provider – State Management
3.  GoRouter – Navigation
4.  REST API Integration (TMDB)

This app demonstrates scalable state management, structured routing, API handling, and production-level Flutter development practices.
